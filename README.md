# 🏠 RentWise AI

> **Smart Rental Price Analytics & Property Recommendation System**

A full-stack web application that helps tenants find fair rental prices and landlords set optimal rent using **Data Analytics** and **Machine Learning**.

---

## 📌 Problem Statement

In India, people renting homes struggle to find accurate rental price information. The same locality shows different rents on different platforms.

## 💡 Solution

RentWise AI is a centralized platform where:
- 🏘️ Landlords list properties
- 🔍 Tenants search with smart filters
- 📊 Data Analytics shows area-wise rent trends
- 🤖 Machine Learning suggests **Fair Rent**
- ⭐ Fair Rent Score (0-100) for every property
